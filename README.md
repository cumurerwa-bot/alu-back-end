# ALU Back-End

This repository contains Python scripts for working with the JSONPlaceholder API.

## Tasks

### Task 0: Gather data from an API
The script retrieves an employee's information and TODO tasks, then displays completed tasks.

Usage:
./api/0-gather_data_from_an_API.py EMPLOYEE_ID

### Task 1: Export to CSV
The script retrieves employee information and TODO tasks and exports them to a CSV file.

Usage:
cd api
./1-export_to_CSV.py EMPLOYEE_ID

The generated CSV contains the user ID, username, task completion status, and task title.

## Requirements
- Python 3
- Internet connection
